Your workout record book

Keep planned and performed sets separate. Create exercises, templates and sessions; record weight, kg/lb and repetitions. Compare a previous completed session by exercise, original unit and set type. Copied values remain unfinished until you mark them complete. A missing value is different from a recorded zero.

Correct and reopen

Use Undo and Redo to correct records. Display-unit changes preserve the original entries. Totals of weight × repetitions are bookkeeping values grouped by unit and set type, not strength estimates or training advice. The isolated Practice guide uses example records and does not replace your own ledger.

CSV and full backup

Record CSV uses the Set Ledger format, with an explicit keep/replace choice for conflicting IDs; it is not a universal workout-app importer. CSV is limited to 16 MiB. A full JSON backup, limited to 64 MiB, includes records, plans, workspace drafts, undo/redo and retained original CSV bytes. Language and guide preferences are separate. 1 MiB = 1,048,576 bytes.

Restore and recovery

Save a separate backup before replacement. Restore validates the selected backup and asks before replacing the current ledger; it does not merge full backups. If the ledger cannot open, Retry or explicitly select and confirm a valid backup. Recovery retains original database preservation copies on the device; it does not silently create an empty ledger. A backup is readable, not encrypted.

Delete and share

Delete all local records includes app-owned records, history, drafts, stored CSV originals and verified recovery copies. If cleanup is pending, follow the app’s status rather than assuming it finished. External originals, previously shared files and device/OS backups are managed separately. This is logical deletion, not guaranteed physical erasure. Files providers and destinations selected in the iOS share sheet may use the network.
