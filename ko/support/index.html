나만의 운동 원장

계획과 실제 수행 세트를 나누어 기록합니다. 운동·템플릿·세션을 만들고 무게·kg/lb·횟수를 입력합니다. 같은 운동·원래 단위·세트 유형의 이전 완료 세션과 비교합니다. 가져온 값은 직접 완료하기 전까지 미완료이며 미입력과 기록한 0은 다릅니다.

정정과 다시 열기

되돌리기·다시 실행으로 기록을 정정합니다. 표시 단위를 바꾸어도 원래 입력을 보존합니다. 중량 × 횟수 합계는 단위·세트 유형별 장부 수치이며 근력 추정이나 운동 권장이 아닙니다. 연습 안내는 개인 원장과 분리된 예제를 사용합니다.

CSV와 전체 백업

CSV는 Set Ledger 기록 형식이며 같은 ID 충돌 시 유지·교체를 선택합니다. 모든 운동 앱의 파일을 읽는 범용 가져오기가 아닙니다. CSV는 16 MiB, 전체 JSON 백업은 64 MiB 한도입니다. 전체 백업에는 기록·계획·작업 초안·되돌리기/다시 실행·보관한 CSV 원본이 포함됩니다. 언어와 안내 환경설정은 별도입니다. 1 MiB = 1,048,576바이트입니다.

복원과 복구

교체 전 별도 백업을 저장하세요. 선택한 백업을 검증하고 확인 후 현재 원장을 교체하며 전체 백업을 병합하지 않습니다. 원장이 열리지 않으면 재시도하거나 유효한 백업을 직접 선택·확인합니다. 복구는 기존 데이터베이스 보존 사본을 기기에 남기며 빈 원장으로 몰래 초기화하지 않습니다. 백업은 읽을 수 있는 파일이며 암호화되지 않습니다.

삭제와 공유

전체 로컬 삭제는 앱의 기록·내역·초안·CSV 원본과 확인된 복구 사본을 대상으로 합니다. 정리 대기가 표시되면 완료로 간주하지 마세요. 외부 원본, 이미 공유한 파일과 기기/OS 백업은 별도 관리합니다. 논리적 삭제이며 저장장치의 물리 소거를 보장하지 않습니다. iOS 파일 제공자나 공유 대상으로 선택한 서비스는 네트워크를 사용할 수 있습니다.
